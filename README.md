# ChatGPT Spring Boot Labs

A practical, chapter-by-chapter Spring Boot learning repository built around **Tapri Cloud**, a fictional ordering platform.

## Learning approach

Each chapter focuses on:
1. Why the concept matters in a real backend project.
2. Plain-language explanations and examples.
3. Hands-on tasks with observable acceptance criteria.
4. Interview checks and practical troubleshooting.

## Chapters

| Chapter | Topic | Status |
|---|---|---|
| [01 — Maven and the pom.xml](chapters/01-maven-and-the-pom/README.md) | Maven coordinates, Spring Boot parent, starters, scopes and profiles | Available |

## How to start

Open [Chapter 1](chapters/01-maven-and-the-pom/README.md), read the lesson, then complete the tasks in its practice `pom.xml`.

Track your learning in [PROGRESS.md](PROGRESS.md).

> The practice POM is intentionally incomplete. Complete the chapter tasks before expecting the project to build.
