# ChatGPT Spring Boot Labs

A practical, chapter-by-chapter Spring Boot learning path built around **Tapri Cloud**, a fictional ordering platform.

## Learning method

Every chapter provides the purpose of the concept, plain-language explanations, a realistic backend scenario, implementation tasks, acceptance checks and an interview checkpoint. Complete the tasks yourself; do not mark progress until you can explain and reproduce the work.

## Getting started

1. Start with [Chapter 1 — Maven and the pom.xml](chapters/01-maven-and-the-pom/README.md).
2. Continue in chapter order so each concept builds on the previous one.
3. Use the practice POMs and TODO comments where provided.
4. Track actual completion and revision notes in [PROGRESS.md](PROGRESS.md).

**Scope note:** All 41 chapters have learning material and practical task outlines. Runnable implementation code and automated test suites will be expanded progressively as you work through each chapter; a chapter README does not claim every exercise is already implemented or verified.
